# Player life arc — original concept sprite sheet

This first original art pass covers a crawling infant, toddler, child, teen, young adult, midlife adult, elderly woman, and elderly man. The source master is the generated design sheet; the eight 24×32 PNGs and combined atlas are nearest-neighbor reductions with a hard alpha threshold.

These are **concept sprite studies**, not integrated runtime actors. They are static south-facing poses. Four-direction walking/idle/interact frames, modular appearance layers, age-transition continuity, and device rendering remain to be authored and reviewed before integration. No third-party pack art was copied into these files.

See `frames.json` for frame IDs, age tags, sheet coordinates, pivots, source crops, and readiness limits. `player-age-arc-preview-4x.png` is a nearest-neighbor review enlargement; the 96×64 PNG is the actual atlas.
