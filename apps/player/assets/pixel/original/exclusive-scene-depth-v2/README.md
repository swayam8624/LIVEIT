# Exclusive scene depth v2

This is an original, rights-safe 2D pixel concept batch for three important life moments:

- `graduation/` — an open-sky school ceremony with sunset stage lighting.
- `new-parenthood/` — a quiet homecoming scene with a bassinet and family keepsakes.
- `elder-legacy/` — a warm memory room for an elder birthday or legacy handoff.

Every scene is intentionally composable. Each folder contains a 320×256 RGB background plate, a transparent middle-ground set-dressing layer, a transparent foreground frame, a transparent actor-safe placement guide, and four separate transparent story-item sprites. The `*-source.png` files preserve the 640×512 source snapshot used to derive the review layers. The `*-preview-derived.png` files are convenience composites only; they are not the source of truth and must not be imported as a flattened runtime scene.

## Rebuild

From this folder, run:

```sh
python3 build_layers.py
```

The script uses only Pillow and deterministic primitives. It rebuilds all source snapshots, derived layers, previews, `manifest.json`, and `provenance.json`. Rebuilding replaces files generated by this script in this folder; keep any later manual paint-over in a separate reviewed batch.

## Provenance and limits

The art is authored from scratch for LIVEIT and uses no ZIP, web, or third-party image. Prompts and art-direction notes are in `prompts.md`; the deterministic source recipe is `build_layers.py`. `runtimeReady` is `false` throughout. These are visual studies pending palette review, phone-size inspection, actor integration, dialogue-safe camera tests, and explicit catalog admission.
