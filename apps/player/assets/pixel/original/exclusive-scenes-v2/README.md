# Exclusive scenes v2

A refined concept batch for three emotionally distinct life-story beats. V2 preserves the built-in image-generator source outputs and supplies 320×256 concept composites plus separate transparent layout guides. V1 is preserved unchanged.

## Scenes

- `garden-graduation-composite-v2.png` — golden-hour town garden ceremony with graduates, family support, lanterns and a dialogue-safe lower band.
- `new-parenthood-home-composite-v2.png` — warm home welcome with two parents and a wrapped sleeping baby; no medical procedure, hospital or clinical imagery.
- `elder-farewell-legacy-composite-v2.png` — blue-hour family room with an elder, listener, keepsake box, memory table and rain window; no funeral imagery or depiction of death.
- `*-composite-source.png` — exact unmodified built-in generator outputs, retained at their native 1402×1122 RGB dimensions.
- `*-layout-guide.png` — transparent 320×256 placement guides showing actor boxes, optional baby/prop box, pivot marks and the advisory lower dialogue-safe band.

## Provenance

Generated on 2026-10-20 with the built-in image generator. The exact prompts and negative constraints are preserved in [prompts.md](prompts.md). No supplied archive, downloaded art, external image reference, logo, font or copyrighted character was used. The source outputs are copied unchanged from the generator output directory; the `*-composite-v2.png` files are resized 320×256 working concepts and the layout guides are independently authored transparent guides.

`manifest.json` records exact dimensions, alpha expectations, SHA-256 hashes, source preservation, anchors/safe region, and `runtimeReady: false` at batch, scene and file level. The generated images are concept composites, so clean separated actor/background alpha plates are intentionally not claimed. The layout guides are the separate current-layer staging aids.

These assets remain concept-only pending manual pixel cleanup, native-size legibility and crop review, palette accessibility review, layer separation, actor pivot/animation work and native renderer acceptance. This folder does not modify runtime code or catalogs.
