# Appearance directional v1

This package is an original, deterministic starter for LIVEIT's modular
24×32 actor appearance system. It keeps the existing south-facing
`appearance-kit-v1` untouched and adds separately authored south, west, east,
and north layer sets.

## Contents

- `layers/<direction>/skin/`: four skin-tone body layers (`porcelain`,
  `copper`, `umber`, and `deep`)
- `layers/<direction>/hair/`: four hair layers (`coiled`, `silver_coiled`,
  `cropped`, and `braided`)
- `layers/<direction>/top/teal-24x32.png`: teal top
- `layers/<direction>/bottom/ochre-24x32.png`: ochre bottom
- `layers/<direction>/shoes/ochre_boots-24x32.png`: ochre/ink shoes
- `layers/<direction>/accessory/`: scarf, satchel, and cane
- `composites/`: four sample identities, each rendered in all four facings
- `appearance-directional-preview-4x.png`: nearest-neighbor review sheet
- `manifest.json`: dimensions, pivot, layer order, hashes, and readiness flags
- `provenance.json`: authorship and source statement
- `generate_directional_appearance.py`: reproducible source/build script

The frame is RGBA `24×32` with a shared bottom-center pivot of `[12, 28]`.
The required occlusion order is:

```text
skin → bottom → top → shoes → hair → accessory
```

The order is intentionally recorded in both `manifest.json` and
`provenance.json`; runtime code should composite in this order so hair and
accessories can cover the body while clothing remains below the head.

## Direction authorship

Each direction has its own coordinate branch in the build script. Profile
facings include a one-pixel nose and offset limbs; north-facing heads have
back-of-head highlights; south-facing faces include eyes and a mouth. The
west and east branches were authored independently and are not generated by
flipping one another.

## Provenance and readiness

All pixels come from Pillow drawing primitives and the hand-authored palette
in `generate_directional_appearance.py`. No ZIP archive, third-party asset,
internet image, or AI-generated source is used. The earlier
`appearance-kit-v1` folder was used only to confirm the shared frame and pivot
convention; no pixels were copied and that folder was not modified.

Every PNG is recorded as `RGBA`, `24×32`, with a SHA-256 in `manifest.json`.
Every layer and composite has `runtimeReady: false`. This is a compositing
starter, not an integrated runtime pack: walk phases, age-specific clothing,
renderer import, accessibility/palette review, and collision/touch review are
still required before adoption.

## Rebuild

From the repository root, run:

```sh
/Users/swayamsingal/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3 \
  apps/player/assets/pixel/original/appearance-directional-v1/generate_directional_appearance.py
```

The script deterministically rewrites only this package's `layers/`,
`composites/`, preview, manifest, and provenance files.
