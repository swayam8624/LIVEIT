# Player adult expressions — original concept sprite sheet

Twelve emotion studies for the auburn-haired adult player identity: neutral, happy, sad, angry, flirty (adult-only), shocked, scared, smug, crying, embarrassed, tired, and thoughtful. Each portrait exports as a transparent 96×128 PNG; the atlas and 2× nearest-neighbor review image are included.

These are static expression frames, not a finished facial animation rig. The flirty frame is adult-only and must never be selected for minor ages. See `frames.json` for IDs, cell bounds, age gate and limitations.
