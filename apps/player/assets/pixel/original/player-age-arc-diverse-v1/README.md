# Diverse player life arc — original concept sprite sheet

A second original appearance study adds a deep-brown skin palette, coiled-to-silver hair progression, sky-blue signature accents, and elder woman/man presentations across eight ages/variants.

The eight 24×32 frames and combined atlas are nearest-neighbor reductions with a hard alpha threshold. These are **concept sprite studies**, not integrated runtime actors. They are static south-facing poses. Four-direction animation, modular appearance layers, age-transition continuity, and device rendering remain to be authored and reviewed.

See `frames.json` for IDs, age tags, sheet coordinates, pivots, source crops, and readiness limits. `player-age-arc-diverse-preview-4x.png` is a nearest-neighbor review enlargement; the 96×64 PNG is the actual atlas.
