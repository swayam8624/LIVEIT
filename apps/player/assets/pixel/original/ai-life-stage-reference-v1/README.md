# AI life-stage and movement references v1

This isolated AI concept batch introduces one original woman identity across seven ages: crawling infant, toddler, child, teen, young adult, midlife adult, and elder. A separate elder movement-sheet concept uses the same silver-braided elder identity.

## Review files

- `age-lineup-transparent-candidate.png` — seven-stage front-facing lineup with a real transparent alpha channel. It has soft painted texture and colored edge fringe, so use it only as an identity and age-proportion reference.
- `elder-walk-cycle-concept.png` — a four-row/four-pose-per-row concept for south, west, east, and north. The AI did not guarantee measured equal cells or a shared pixel pivot; poses and cane cadence need hand cleanup.
- `source/original-lineup-master.png` — original generated master. Its checkerboard is baked into the RGB pixels, so it is retained only as lineage evidence.

The lineup is static, and the elder walk page is a loose unmeasured concept. Neither is a runtime-ready sprite atlas. The project’s existing cycle packs remain the reliable source for direction/state coverage. All records remain `runtimeReady: false`.

No supplied ZIP art or web images were used. Confirm current provider terms before commercial redistribution. See `manifest.json` and `provenance.json` for exact prompts, hashes, alpha statistics, and limitations.
