# World effects batch v1

Original pixel overlays for rain, snow, autumn leaves, and night lights, plus a five-frame pixel iris transition. Each weather family has eight 32×32 transparent frames; iris frames are 48×48. Frames are individual files and packed in nearest-sampled atlases.

All artwork was generated deterministically with integer-coordinate drawing in `generate_fx.py` on 2026-10-20. No downloaded, supplied-archive, or third-party assets or references were used. Metadata and frame limits are in `frames.json`. These are visual prototypes with runtimeReady false; particle density, palette integration, timing, accessibility contrast, and renderer performance still need review.
