# Prompt record

## Lineup source

Use case: stylized-concept. Asset type: original pixel-art character age and identity reference sheet for a life-simulation game. Create a clean 4 by 2 reference sheet of eight distinct human character identities in a cohesive premium top-down pixel-art style. Rows are life stages: child, teen, adult, elder. Columns are two clearly distinct identities per stage. Show each character in a neutral standing three-quarter pose, full body, centered in a square cell, with enough empty margin around each figure. Vary skin tone, hair texture, hairstyle, body shape, clothing silhouette, mobility aids where age appropriate, and gender presentation. Keep the design family diverse and readable at small sprite scale. Deep navy solid background with subtle cell separators, no environment. Exactly one character per cell. Hand-crafted 16-bit inspired pixel art, crisp hard-edged clusters, controlled palette, no anti-aliasing, no 3D render. No logos, watermark, copied franchise characters, or text.

## Movement source

Use case: stylized-concept. Asset type: original pixel-art movement reference sheet for a life-simulation game. Create an 8-panel movement study for eight original human identities matching a cohesive premium top-down pixel-art game style. Exactly eight panels in a 4 by 2 grid: child A, child B, teen A, teen B, adult A, adult B, elder A, elder B. In each panel, show the same character repeated in a clean four-frame walk mini-cycle facing the viewer in a top-down three-quarter view: contact, passing, contact opposite, passing opposite. Keep the identity, outfit, hair silhouette and body proportions consistent across the four frames in each panel. Vary skin tone, hair texture, hairstyle, body shape, clothing silhouette, mobility aids where age appropriate, and gender presentation between identities. Deep navy solid background, no environment, no logos, watermark, copied franchise characters, text, extra characters, or cropped feet.
