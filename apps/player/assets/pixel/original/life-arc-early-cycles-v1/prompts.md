# ImageGen prompts

These are the verbatim prompts used for the four preserved source sheets. The
only input images were the local reference crops named in each prompt. No
supplied ZIP or third-party art was used.

## Infant crawl

> Use case: stylized-concept. Asset type: original pixel-art game sprite sheet. Input image: Image 1 is a visual identity reference for the same player character, not to copy literally. Create one clean transparent-background 4×4 sprite sheet for the same player identity as an infant crawler. Layout exactly 4 columns by 4 rows, identical cells, transparent gutters, no labels or text. Rows top to bottom: south-facing, west-facing, east-facing, north-facing. Columns left to right: contact-a, passing-a, contact-b, passing-b. Deep-brown-skinned infant, short coiled dark hair, tiny sky-blue signature clothing accent, small stable facial mark; age-appropriate crawling proportions. Each frame is a distinct readable crawl phase with hands and knees shifting naturally, care-safe and non-romantic. Crisp hand-authored pixel clusters, limited warm palette, dark outline, consistent scale and silhouette, no scenery, no ground shadow, no UI, no watermark. Source concept sheet for deterministic 24×32 extraction; prioritize clear cell separation and exact cardinal direction readability.

Reference: `player-age-arc-diverse-v1/infant-crawler.png`
