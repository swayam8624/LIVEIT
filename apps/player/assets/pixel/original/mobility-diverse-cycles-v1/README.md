# Mobility-diverse cycles v1

Original deterministic concept sprites for two adult characters: Rhea uses a powered wheelchair and Samir uses a manual wheelchair. Each has four independently authored cardinal directions, four locomotion phases, and idle/interact poses (48 frames per character; 96 total). The 32×40 logical canvas uses pivot `(16,39)`, transparent RGBA output, and nearest-neighbour review atlases. Chair geometry is part of each silhouette; side views include wheel/rim mechanics, while interaction poses operate the controls or reach for a cane.

No supplied ZIP, third-party sprite, logo, or external reference image was used. `runtimeReady` is false pending pixel-art cleanup, palette review, collision/pivot checks, renderer import, and human visual approval.
