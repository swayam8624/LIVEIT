# Appearance directional v2

This is a small, isolated original batch extending the modular appearance kit
to four cardinal directions. It is a review package only and is not registered
with the player runtime or the shared production catalog.

## Contents

- `layers/<direction>/`: two skin tones, two hairstyles, two torso outfits,
  trousers, sneakers, and a satchel for `south`, `west`, `east`, and `north`.
- `composites/<identity>/`: two sample identities rendered in all four
  facings.
- `appearance-directional-v2-atlas-4x.png` and `atlas.json`: nearest-neighbor
  review atlas and frame coordinates.
- `manifest.json`: dimensions, pivot, layer order, SHA-256 hashes, and
  `runtimeReady: false` records.
- `provenance.json`: authorship and source boundaries.
- `generate_directional_appearance.py`: deterministic builder.

Every PNG is transparent RGBA on a 24×32 logical canvas with bottom-center
pivot `[12, 28]`. Composition order is:

```text
skin → bottom → top → shoes → hair → accessory
```

Hair and torso cues use explicit coordinate branches for each direction. The
profile faces carry the satchel and seam details on their facing side, while
the north hair and jacket include back-of-head and back-panel cues. No frame
is generated by mirror-flipping another frame.

## Provenance and limitations

All pixels are original Pillow primitives and a hand-authored palette. The
existing original appearance kit was inspected only for its frame, pivot, and
modular layering convention; no ZIP contents, third-party art, or source
pixels were used. This batch is not production-ready: it needs renderer
import, palette/accessibility review, walk phases, age variants, collision and
touch review, and human art direction before adoption. Every manifest record,
including the atlas and package root, sets `runtimeReady` to `false`.

## Rebuild

From the repository root:

```sh
/Users/swayamsingal/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3 \
  apps/player/assets/pixel/original/appearance-directional-v2/generate_directional_appearance.py
```

The builder rewrites only this package's generated PNGs, `atlas.json`,
`manifest.json`, and `provenance.json`.
