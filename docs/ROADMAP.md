# Roadmap and evidence boundary

## Implemented foundation

Typed and validated shared world/story model; deterministic simulation; restricted effects; branching runtime; local versioned saves; separate life/story continuities; Expo screens; original reunion with three endings; Next.js authoring/validation/export; regression tests; CI definition; architecture and production boundaries.

## Next: finish the vertical slice

1. Expand the narrative to a paced 10–20-minute experience, with conditional later dialogue recalling established facts, a bookshop follow-up and player-tested balancing.
2. Add a validated file-import flow in the player and structured Studio choice editing, then prove exported content works across web and native before calling it publication.
3. Add accessibility and reduced-motion settings, mobile safe areas, production art concepts and a measured scene-renderer prototype.
4. Test on physical iOS and Android devices. Capture startup, memory, animation and save behavior, including failed writes and suspended/resumed apps.
5. Add replay fixtures, explicit save migrations, history compaction and multi-tab conflict handling.

## Later production gates

Accounts and conflict-aware cloud sync; PostgreSQL/API/object storage; immutable publication; rights and moderation policies; review and appeals; discovery; creator assets; signed package verification; localization; native distribution credentials and store testing. No payments, cloud services, deployments, public community or store publication are implied by this repository.
