Verified initial source shortlist for the 1,481-item LIVEIT production catalog and selected 110-item first playable kit. **These are acquisition recommendations, not downloaded files, successful tested game assets or license clearance of each component.** Link checking cannot establish which sources a particular Codex session is blocked from accessing; links marked MANUAL are known click/login/large/custom-license candidates. Before raw files go into a _public_ GitHub repo, check the license bundled with the exact downloaded item, any trademarks/model releases, license date and that site's actual source-file redistribution rights.

## Download handling — very important

- **YES / CC0:** generally suitable for public version control, subject to exact file provenance; license text still keep in `assets/licenses`. Large source masters may require Git LFS or secure external storage.
- **YES with terms:** e.g., MIT needs copyright/license notice, CC BY requires creator/link/change attribution; OFL font needs corresponding font copyright/license and Reserved Font Name compliance.
- **NO public repo raw:** QAL v1, CraftPix custom, Mixamo, Sonniss, and game-use-only source archives are NOT something to indiscriminately commit to public GitHub. They may be usable inside compiled games when terms permit; keep private local/team storage and provenance link in Git; do not blindly encode them as extractable distributed DLC packs.
- **License unknown:** no download into repo until exact source record and archive license are verified.
- **Manual download workflow:** click official item, choose free/$0 if applicable, download original archive; save publisher URL, snapshot of terms and download date, computed SHA-256; copy into the intended `assets/manual-inbox/...` path, then run import/validation. Do not rename an existing proprietary file "CC0".

## User-to-Codex handoff

1. Download the high-priority YES/CC0 entries first. Keep zip files intact for provenance outside shipped game bundles; extract source into a known staging folder, never overwrite working source.
2. Store manually fetched CC0 files in `assets/manual-inbox/cc0/<category>/<publisher>/<pack-version>/`, MIT icons in `assets/manual-inbox/mit`, fonts in `assets/manual-inbox/ofl`, each with an adjacent `LICENSE` and `SOURCE.json` recording URL, dated rights proof, sha256.
3. DO NOT commit restricted-license original source ZIPs to public LIVEIT. Store them separately in an access-controlled local storage directory; commit only pointer/metadata and approved runtime compiled-game integrations when exact contract permits.
4. Tell Codex: `Scan assets/manual-inbox, verify SHA-256 and rights per file, map source assets to 110 IDs in content/production-assets/v1/first-playable-slice.json, import/convert, author the missing geometry/sprites/maps/animations, run npm run assets:validate and npm run check, integrate working runtime assets, commit and push legal deliverables.`
5. Expected mismatch: modern-life 3D hero faces (player and Amelia) with cinematic expression/aging are not solved by Kenney/KayKit alone; use MPFB core original exports as legally clear mesh foundation then actually sculpt/rig/texture them.
